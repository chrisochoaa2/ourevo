# Revelation Outdoors OU link hub

This site is intentionally simple and works like a linktree-style landing page.

## Edit the links
Open `index.html` and replace:
- the Instagram URL
- the Google Sheets/interest-form URL
- any other links you want to feature

## Publish on GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Set the source to the `main` branch and `/ (root)`.
4. Save and wait for the Pages URL to appear.
